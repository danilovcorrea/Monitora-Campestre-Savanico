# Monitora 3.0.0

Execute somente `monitora_campsav_alvo_global_v3.0.0.R` no RStudio.
O script obtém os arquivos de apoio conforme as opções habilitadas.

- [Guia de início](GUIA_USUARIO_v3.0.0.md)
- [Manual completo em PDF](manual_usuario/manual_usuario_v3.0.0.pdf)
- [Manual navegável](manual_usuario/manual_usuario_v3.0.0.html)
- [Notas da versão](RELEASE_NOTES_v3.0.0.md)
- [Código e histórico públicos](https://github.com/danilovcorrea/Monitora-Campestre-Savanico)

Os dados de entrada são fornecidos pelo usuário. Preserve a rodada anterior
e siga os percursos de curadoria e geração de produtos descritos no manual.
O pacote contém software e documentação; os produtos das UCs têm entrega própria.
